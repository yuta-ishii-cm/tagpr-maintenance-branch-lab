# やりたいことと方針

## 前提とする状況

- 機能は通常リリース、バグ修正は hotfix で本番に出している
- main には、まだ本番に出していない機能が入っている。そのため、hotfix は main からは出せない
- hotfix の候補は同時にいくつも走り、出す時期もバラバラ
- リリースの管理には [tagpr](https://github.com/Songmu/tagpr) を使っている。main が更新されるとリリース PR ができて、それをマージするとタグと GitHub Release ができる

## 困っていたこと

tagpr は main のリリースしか面倒を見てくれないので、hotfix では tagpr がやってくれる処理を手で代わりにやっていました。

- 前回リリースしたタグから hotfix ブランチを作る
- versionFile（デプロイするイメージのタグを書いたファイル。複数ある）を書き換える
- CHANGELOG.md を追記する
- タグと GitHub Release を作る
- tagpr が先に作っていたリリース PR を Close する
- hotfix ブランチを main に取り込む PR を作る（コンフリクトしたら手で解消）

手順が多いうえに、漏れると以降の通常リリースが壊れます。main への取り込みとリリース PR の Close が抜けた結果、main の versionFile が古いまま残り、tagpr が誤ったバージョンでリリース PR を作り続けたことがありました（理由は [tagpr で詰まった点](./tagpr-pitfalls#latest-tag) を参照）。

hotfix の候補が複数あると、ブランチの切り方・番号の振り方・取り込む順番をその都度決める必要もありました。

## やりたいこと

1. hotfix を「修正 PR をマージして、ワークフローを実行する」だけにする

2. 候補が複数あっても、「どれから出すか」を決めるだけで済むようにする

3. 漏れると壊れる手作業をなくす。ずれた状態になったら、ワークフローが止まって気づけるようにする

4. 機能リリースは、今までどおり tagpr で回す

## 方針

| 決めたこと | 内容 |
| --- | --- |
| 保守ブランチ | 本番で動いている系統（vX.Y）ごとに `release/vX.Y` を持つ。機能リリースのタグ（vX.Y.0）から自動で作る |
| ツールの分担 | tagpr は main（機能リリース）専用。保守ブランチのリリースは自前のワークフロー HOTFIX_RELEASE で行う |
| 番号 | 機能リリースは minor、hotfix は patch を上げる |
| 同期 | hotfix の修正は、古い系統から新しい系統・main へ一方向に流す。同期 PR は自動で作る |
| ずれの検知 | main の versionFile が最新タグより古いときや、同期 PR のマージ待ちのときは、tagpr を止める |

tagpr を保守ブランチでも動かさなかった理由は、[tagpr で詰まった点](./tagpr-pitfalls) にまとめています。

## この検証でやっていないこと

- デプロイそのもの。検証リポジトリの `deploy/{dev,pro}/image-tag.jsonnet` は、versionFile の書き換えを確かめるためのダミーです（`pro` が本番）
- 中身のコンフリクトの自動解消。versionFile と CHANGELOG.md 以外のファイルがコンフリクトしたら、人に回します
- 保守ブランチの保護（ruleset）。保護するときの注意は [残った課題](./open-issues) を参照してください
- 保守ブランチごとの検証環境。この検証では扱っていません

## 用語

| 用語 | 意味 |
| --- | --- |
| 系統 | `vX.Y` が同じリリースの並び（v1.1.0・v1.1.1・v1.1.2 は v1.1 系統） |
| 保守ブランチ | 系統ごとの hotfix 用のブランチ `release/vX.Y` |
| 機能リリース | main から tagpr で出すリリース（vX.Y.0） |
| hotfix | 保守ブランチから HOTFIX_RELEASE で出すリリース（vX.Y.1 以降） |
| 修正候補 | 保守ブランチに向けて開いている、hotfix の修正 PR |
| 同期 PR | hotfix のタグを、新しい保守ブランチや main に取り込む PR（`sync/<タグ>-to-<同期先>`） |
| versionFile | tagpr がバージョンを書き込むファイル。`.tagpr` の `versionFile` で指定する |
